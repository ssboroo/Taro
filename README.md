# RAINY Тарот

Бүрэн Монгол интерфэйстэй, Rider–Waite–Smith 78 картын сан, нэг/гурван картын дэлгэлт, Waite-ийн дараалалтай Кельтийн загалмай. Arcanamana-гийн минимал, карт төвтэй санаанаас урам авсан өөрийн дизайн; түүний код, зураг, брэндийг хуулбарлаагүй.

## Ажиллуулах

Node.js 22+ шаардлагатай. Гадаад npm dependency байхгүй.

```sh
npm test
npm run check
npm start
```

`http://localhost:3000` хаягаар нээнэ. `PORT` орчны хувьсагч дэмжинэ. Railway-д repository холбож `npm start` ажиллуулна. `/health` нь health check. Vercel, Pages болон бусад static hosting дээр `public/` хавтсыг шууд нийтэлж болно. API түлхүүр шаардахгүй.

## Боломжууд

- 78 картын нэр, шулуун/урвуу утга, тус бүрийн дүрслэлийн ажиглалт ба эргэцүүллийн асуулт.
- Масть ба нэрээр хайх, дэлгэрэнгүй тайллын цонх.
- Web Crypto + rejection sampling + Fisher–Yates: давхардалгүй сонголт.
- Кельтийн загалмайд төлөөлөх картыг багцаас хасаж, холисон багцыг 3 удаа тасална. 1–10 байрлалын дараалал нь Waite III §7.
- Урвуу картыг тусад нь асаана. 50% магадлал нь техникийн шийдэл, түүхэн заавар биш.
- Карт нэг нэгээр нээх, байрлал тус бүрийн тайлал, локал тэмдэглэл, текст экспорт, хэвлэх.
- Гар утасны layout, keyboard navigation, native dialog, reduced motion.

## Эх сурвалж ба ил тод хязгаар

1. V&A, [A history of tarot cards](https://www.vam.ac.uk/articles/tarot-cards): XV зууны тоглоомын гарал, хожуу үеийн мэргэ төлгийн хэрэглээ.
2. A. E. Waite, [The Pictorial Key to the Tarot (1911)](https://sacred-texts.com/tarot/pkt/index.htm): III §3 их аркан, II §2 бага аркан, III §7 дэлгэлт. Карт бүрийн утгын эх холбоос тусдаа бий.
3. Pamela Colman Smith-ийн Rider–Waite–Smith (1909) дүрслэл, [зургийн сан ба гарал](https://github.com/seven102161/elaine-tarot-cards), pinned revision `2ff81c8d325c08690de85260fedede241cd33449`. Нийтийн өмчийн эх дүрслэл. Зураг гадаад GitHub raw/CDN-ээс ачаална, тасарвал нэр ба тайллыг харуулна. Зургийг бүрэн offline багцлаагүй. Түүхэн зургийн Англи бичгийг хэвээр хадгалсан; бүх аппын текст Монгол.

Монгол тайлбарууд нь эхийн **сонгосон хураангуй**, үгчилсэн бүрэн орчуулга биш. Дүрслэлийн ажиглалт, мастийн хүрээ, асуултууд нь редакцын давхарга. Эхийн хуучны эмнэлгийн, хүйсийн хэвшмэл нэршлийг онош, бодит зөгнөл болгоогүй. Нэг, гурван картын дэлгэлт нь орчин үеийн хувилбар; эртний нийтлэг дүрэм гэж нэрлээгүй.

Кельтийн загалмайн дүр зүүн харсан гэж тогтоосон: 5 баруун, 6 зүүн. Төлөөлөх картыг гадаад төрхөөр бус сэдвээр сонгоно. 2-р картын хөндлөн байрлал нь урвуу гарсан эсэхээс тусдаа. Дэлгэлт бүрд нөхцөлт боломж, эргэцүүлэл санал болгоно; ирээдүйг найдвартай зөгнөдөг гэсэн нотолгоо, амлалт өгөхгүй.

Тэмдэглэл зөвхөн localStorage-д (сүүлийн 100) хадгалагдана. Серверт асуулт илгээхгүй. Бүртгэл, төхөөрөмж хооронд синк, админ самбар байхгүй. Дэлгэлтийн тайлал QPay нэртэй төлбөрийн хаалттай; нэг дэлгэлт 5,000₮. Зураг ачаалах үед гадаад сервер хүсэлт авна.

## Баталгаажуулалт

`npm test` нь 78 картын бүрэн байдал, тусдаа 78 дүрслэл, давхардалгүй сонголт, төлөөлөх карт хасах, урвуу тохиргоо, санамсаргүй тооны bias арилгалтыг шалгана. `npm run check` нь JavaScript syntax шалгана.

## WebGL 3D интерфэйс

Нүүр хуудас: харанхуй fullscreen орон зай, том RAINY TAROT typography, гүн/хэтийн төлөвтэй 24 карт, pointer parallax. Карт сонголт: бүтэн 78 картын эргэлдэх тойрог, 1/3/10 картын төрөл сонгох алхам, hover өргөлт, эргэлт ба төв рүү ойртох animation, Монгол тайлал, хурдан хадгалалт. Хөдөлгөөн зогсоох товчтой.

`scene.js` нь dependency-гүй native WebGL shader renderer, `scene-math.js` нь perspective/model matrix ба projected polygon hit detection. Pixel ratio 1.5-аар хязгаарлагдана; хуудас харагдахгүй үед rendering зогсоно. Зураг нэг удаа texture cache-д ачаална. Reduced motion тохиргоог хүндэтгэнэ.

WebGL байхгүй эсвэл context тасарвал CSS 3D карт, ижил сонголт ба тайлал руу автоматаар шилжинэ. Шалгалтын cloud браузер WebGL context өгдөггүй байсан тул CSS 3D fallback, карт сонгох, тайлал, хайлтын урсгалыг браузерт шалгасан; GPU shader хувилбарыг WebGL дэмждэг бодит төхөөрөмж дээр дахин нягтлах шаардлагатай. Matrix projection, perspective scaling, rotated-card picking-ийн 3 тест нэмэгдсэн (нийт 14 тест).

Бүтэн багцын сонголт: Нэг болон гурван картын дэлгэлт 78 картыг бүгдийг ашиглана. Кельтийн загалмайд төлөөлөх картаа тусад нь сонгож, үлдсэн 77-оос 10 авна. Сэдэв болон асуулт оруулах боломжтой. Алтлаг хээтэй картын шинэ ар тал `public/card-back.svg` нь сайтад зориулсан өөрийн вектор бүтээл; WebGL ба CSS хувилбар нэг дүрслэл ашиглана. Тойрог автоматаар эргэнэ; сум, гулсуураар дурын картыг төвд авчирч сонгож болно. Давтан сонголт хориглогдоно; сонгосон дараалал, урвуу утга хадгалагдана.

## Тайллын студи ба сошиал экспорт

Картын гоёмсог тайллын дэлгэц, богино/бүрэн горим, олон картын filmstrip. Story 1080×1920, пост 1080×1350, дөрвөлжин 1080×1080 PNG бэлтгэнэ. Бүрэн тайлал урт бол таслахгүйгээр дараагийн хуудсанд үргэлжилнэ. Текстийг засаж, хуулж болно. Хувийн асуулт анхдагчаар экспортод орохгүй; тэмдэглэл автоматаар хуваалцахгүй. Web Share file support байвал хэрэглэгч төхөөрөмжийнхөө аппыг сонгоно; үгүй бол PNG татаж сошиал аппдаа оруулна. Facebook/Instagram/Threads рүү автоматаар пост нийтлэхгүй, платформын шууд API интеграци байхгүй. Эх зураг CORS-оор ачаалагдахгүй бол экспортын тодорхой алдаа харуулж, текст хуулах сонголтыг хадгална.


## Тайллын төлбөр · 5,000₮

Карт сонгох, 78 картын ерөнхий лавлах үнэгүй. Тухайн дэлгэлтийн богино/бүрэн/нэгдсэн тайлал, зураг болон текст экспорт зөвхөн серверээр төлбөр баталгаажсаны дараа нээгдэнэ. Нэг төлбөр нь нэг өөрчлөгдөхгүй дэлгэлтэд хамаарна. Ижил дэлгэлтээ дахин нээхэд дахин нэхэмжлэхгүй; шинэ дэлгэлт тусдаа төлбөртэй.

Хэрэглэгчид харагдах нэр: **QPay**. Серверийн adapter нь өмнөх Socialtool Store / Rainyproptech-ийн Wire payment gateway загварыг ашиглана. QPay операторын бодит ID-гаар хязгаарлана. Gateway-ийн өөрийн hosted хуудасны домэйн, нэрийг манай сайтаас өөрчлөх боломжгүй.

### Production тохиргоо

- `WIRE_MN_API_KEY`: project-ийн `sk_live_…` нууц түлхүүр. Client, GitHub, public файлд хадгалахгүй.
- `WIRE_QPAY_OPERATOR_ID`: тухайн gateway project дээр идэвхтэй QPay операторын **яг ID**. Нэрийг таамгаар бичиж болохгүй.
- `PUBLIC_SITE_URL`: энэ сайтын HTTPS үндсэн хаяг.
- `WIRE_MN_WEBHOOK_SECRET`: заавал биш. Энэ сайтын `/api/payments/webhook` шинэ endpoint-ийн signing secret. Өөр сайтын endpoint-ийн secret-ийг хуулж болохгүй.

Түлхүүр болон операторын ID дутуу бол config `enabled:false`, нэхэмжлэл үүсгэхгүй, тайлал нээгдэхгүй. Mock/sandbox төлбөрийг production-д зөвшөөрөхгүй. Өмнөх Railway төслийн OAuth холболт variable нэрсийг харуулсан боловч утгыг буцаагаагүй тул энэ шинэ сайт руу түлхүүрийг хуулж тохируулаагүй. Бодит төлбөрийн туршилт хийгдээгүй.

Hosted checkout-оос буцсан URL-ийг төлсөн баталгаа болгохгүй. API-аас amount=5000, currency=MNT, status=succeeded, livemode=true, order metadata, intent ID болон selected QPay operator-ийг тулгана. Webhook нь HMAC-SHA256 raw-body signature, 5 минутын timestamp шалгалттай; дараа нь provider-оос дахин шалгана. Polling боломжтой учраас webhook ашиглахгүйгээр ажиллаж болно. Owner-private Sites дээр webhook гадаадаас хүрэхгүй байж болох тул polling-ийг ашиглана; audience-ийг энэ өөрчлөлтөөр нээгээгүй.

### Өгөгдөл ба сервер

`server/synthesis.js` нь браузерт тараагдахгүй. `server/payments.js` нь Worker ба Node аль алинд ажиллана. Sites Worker D1-д захиалга, immutable картууд, токены SHA-256 hash, төлсөн эрх хадгална. `drizzle/0000_tarot_orders.sql` нь эхний schema migration. Асуулт, хувийн тэмдэглэл төлбөрийн API руу илгээгдэхгүй.

Node/Railway хувилбар `node:sqlite` ашиглана. Docker image Node 22. Railway-д persistent volume холбоод `PAYMENT_DB_PATH=/data/payments.sqlite` тохируулж, volume path-ийг container-ийн node user бичих эрхтэй болгоно. Volume-гүй deployment төлбөрийн эрхээ redeploy дээр алдах тул бодит төлбөрийг бүү идэвхжүүл. Sites Worker нь D1 ашиглах тул volume шаардахгүй.

Браузерт буцах холбоосын query дотор нууц токен байхгүй. Токен localStorage-д хадгалагдана. Хэрэглэгч браузерын өгөгдлөө цэвэрлэвэл автоматаар сэргээх боломжгүй; одоогоор account-based cross-device recovery байхгүй. Нэхэмжлэлийн хугацаа дууссан боловч төлсөн байж болзошгүй үед төлөв шалгах товчийг ашиглана; шинэ нэхэмжлэлээр сохроор дахин төлүүлэхгүй.

### Sites Worker build

`node scripts/build-worker.mjs` нь серверийн код болон public asset-уудыг нэг ES module Worker-д багцална. `.openai/hosting.json` дотор `d1: "DB"`, `static`-гүй тохиргоо ашиглана. Runtime нууцуудаа Sites environment settings-д хадгална. `dist/server/index.js` нь generated output.

### Шалгалт

`npm test`: unpaid access denied, өөр дүн/валют/оператор/live mode/order metadata татгалзах, immutable spread, secret token, idempotent checkout, signature/replay timestamp, duplicate webhook, restart persistence болон тайллын хөдөлгүүрийг шалгана. Unit tests provider-ийг mock хийдэг; жинхэнэ гүйлгээг орлохгүй.

Төлөөгүй дэлгэлтийн тайлал/экспорт/хэвлэх/тэмдэглэлийн хэсгийг нууна. Серверээр баталгаажсан эрхээр л хэрэгслүүдийг гаргана. Эвдэрсэн браузерын хадгалалтыг үл тоомсорлож, зөвхөн бүрэн баталгаатай бүтэцтэй дэлгэлтийг сэргээнэ.
