# RAINY Тарот

Бүрэн Монгол интерфэйстэй, Rider–Waite–Smith 78 картын сан, нэг/гурван картын дэлгэлт, Waite-ийн дараалалтай Кельтийн загалмай. Arcanamana-гийн минимал, карт төвтэй санаанаас урам авсан өөрийн дизайн; түүний код, зураг, брэндийг хуулбарлаагүй.

## Ажиллуулах

Node.js 22+ шаардлагатай. Гадаад npm dependency байхгүй.

```sh
npm test
npm run check
npm start
```

`http://localhost:3000` хаягаар нээнэ. `PORT` орчны хувьсагч дэмжинэ. Railway-д repository холбож `npm start` ажиллуулна. `/health` нь health check. Vercel, Pages болон бусад static hosting дээр `public/` хавтсыг шууд нийтэлж болно. API түлхүүр шаардахгүй.

## Боломжууд

- 78 картын нэр, шулуун/урвуу утга, тус бүрийн дүрслэлийн ажиглалт ба эргэцүүллийн асуулт.
- Масть ба нэрээр хайх, дэлгэрэнгүй тайллын цонх.
- Web Crypto + rejection sampling + Fisher–Yates: давхардалгүй сонголт.
- Кельтийн загалмайд төлөөлөх картыг багцаас хасаж, холисон багцыг 3 удаа тасална. 1–10 байрлалын дараалал нь Waite III §7.
- Урвуу картыг тусад нь асаана. 50% магадлал нь техникийн шийдэл, түүхэн заавар биш.
- Карт нэг нэгээр нээх, байрлал тус бүрийн тайлал, локал тэмдэглэл, текст экспорт, хэвлэх.
- Гар утасны layout, keyboard navigation, native dialog, reduced motion.

## Эх сурвалж ба ил тод хязгаар

1. V&A, [A history of tarot cards](https://www.vam.ac.uk/articles/tarot-cards): XV зууны тоглоомын гарал, хожуу үеийн мэргэ төлгийн хэрэглээ.
2. A. E. Waite, [The Pictorial Key to the Tarot (1911)](https://sacred-texts.com/tarot/pkt/index.htm): III §3 их аркан, II §2 бага аркан, III §7 дэлгэлт. Карт бүрийн утгын эх холбоос тусдаа бий.
3. Pamela Colman Smith-ийн Rider–Waite–Smith (1909) дүрслэл, [зургийн сан ба гарал](https://github.com/seven102161/elaine-tarot-cards), pinned revision `2ff81c8d325c08690de85260fedede241cd33449`. Нийтийн өмчийн эх дүрслэл. Зураг гадаад GitHub raw/CDN-ээс ачаална, тасарвал нэр ба тайллыг харуулна. Зургийг бүрэн offline багцлаагүй. Түүхэн зургийн Англи бичгийг хэвээр хадгалсан; бүх аппын текст Монгол.

Монгол тайлбарууд нь эхийн **сонгосон хураангуй**, үгчилсэн бүрэн орчуулга биш. Дүрслэлийн ажиглалт, мастийн хүрээ, асуултууд нь редакцын давхарга. Эхийн хуучны эмнэлгийн, хүйсийн хэвшмэл нэршлийг онош, бодит зөгнөл болгоогүй. Нэг, гурван картын дэлгэлт нь орчин үеийн хувилбар; эртний нийтлэг дүрэм гэж нэрлээгүй.

Кельтийн загалмайн дүр зүүн харсан гэж тогтоосон: 5 баруун, 6 зүүн. Төлөөлөх картыг гадаад төрхөөр бус сэдвээр сонгоно. 2-р картын хөндлөн байрлал нь урвуу гарсан эсэхээс тусдаа. Дэлгэлт бүрд нөхцөлт боломж, эргэцүүлэл санал болгоно; ирээдүйг найдвартай зөгнөдөг гэсэн нотолгоо, амлалт өгөхгүй.

Тэмдэглэл зөвхөн localStorage-д (сүүлийн 100) хадгалагдана. Серверт асуулт илгээхгүй. Бүртгэл, төхөөрөмж хооронд синк, төлбөр, админ самбар энэ хувилбарт байхгүй. Зураг ачаалах үед гадаад сервер хүсэлт авна.

## Баталгаажуулалт

`npm test` нь 78 картын бүрэн байдал, тусдаа 78 дүрслэл, давхардалгүй сонголт, төлөөлөх карт хасах, урвуу тохиргоо, санамсаргүй тооны bias арилгалтыг шалгана. `npm run check` нь JavaScript syntax шалгана.
